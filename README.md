# Wedding Moments Hub

이렇게 누구나 접속 가능한 모바일 청첩장을 만들어주시되, 

1) 히어로 섹션이 뜨기 전에 팝업으로 참석여부 입력, 음악 on/off 설정이 뜨게 해주세요

2) 히어로 섹션에서 실시간 디데이도 뜨게 해주세요

3) 갤러리는 사진 확대 금지를 적용해주세요

4) 일정을 캘린더에 추가할 수 있는 기능을 넣어주세요

5) 계좌번호 복사 가능, 카카오페이 송금 링크, 토스 송금 링크 넣어주시고 복사할 시엔 복사 완료 문구도 넣어주세요

6) 오시는길에 기본정보들과 네이버지도, 카카오맵, 구글맵, 티맵 모두 접근 가능하도록 해주세요 / 차량, 지하철, 버스, 셔틀버스 정보를 넣게 해주세요

7) 사진 업로드가 가능하게 해주세요 일회에 백장씩(구글 드라이브나 네이버 박스 이용)

8) 안내 사항, 주차, ATM, 포토부스를 넣어주시고 FAQ도 넣어주세요(문의사항을 입력하면 제가 답변하도록 해볼까요?)

9) 초대문구의 손편지는 손편지를 스캔하면 손편지만 가져가고 관련 디자인은 꾸며주셔야해요

기본정보 : 신부 최효정, 신랑 이상진, 신부 아버지 최진혁, 신부 어머니 정대영, 신랑 아버지 이승학, 신랑 어머니 박영미

일산 웨스턴빌리프 2027년 03월 14일 13시



또 필요한거 있으면 말씀 주세요
